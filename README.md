## 👋 Hello, I'm Ahmed

I'm **Ahmed Hatem**, a **WordPress developer and MERN full-stack web developer based in Egypt**, building fast, accessible, scalable, and search-friendly websites for businesses and digital products.

My work combines **custom WordPress development**, **Elementor widgets and plugins**, **WooCommerce e-commerce solutions**, and **JavaScript/PHP engineering** with a practical focus on **technical SEO, Core Web Vitals, responsive UI/UX, and maintainable code**. I also use **AI-assisted development (vibe coding)** to explore ideas and accelerate implementation — while keeping architecture, code review, security, and testing firmly in the workflow.

I care about what happens *after* a website launches: how quickly it loads, how easily customers find it, how well it converts, and how confidently its owner can manage it.

> **My approach:** Build for people. Engineer for performance. Structure for search.

## 🔍 Performance Is Part of the Build

A polished interface is only one part of a successful website. I treat **search visibility and technical quality as product requirements**, not last-minute add-ons:

- **SEO foundations:** clean URL structures, semantic headings, crawlable navigation, metadata planning, and structured data where appropriate.
- **Core Web Vitals:** optimize LCP, INP, and CLS through asset strategy, efficient JavaScript/CSS, caching, and image delivery.
- **WordPress performance:** efficient plugin architecture, conditional asset loading, database awareness, and careful cache configuration.
- **Business-focused UX:** responsive layouts, clear calls to action, accessible content, and manageable publishing workflows.

## 🧠 How I Use Vibe Coding

For me, **vibe coding is a speed multiplier, not a replacement for engineering judgment**. I use AI-assisted workflows for exploration, scaffolding, debugging, and iteration, then validate the result with code review, testing, security checks, and performance analysis.

```text
Discover  →  Architect  →  Prototype  →  Build  →  Test  →  Optimize  →  Ship
             human-led engineering + AI-assisted iteration
```

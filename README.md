## 🔍 My Approach: Development + SEO

I don't treat SEO as a checklist added after launch. I build websites with **technical SEO, content structure, accessibility, and performance** in mind from the start.

- **WordPress development:** lean custom plugins, secure code, reusable Elementor components, appropriate caching, and conditional CSS/JS loading.
- **Core Web Vitals:** optimize LCP, INP, and CLS through image strategy, critical rendering, lightweight assets, and efficient JavaScript.
- **Search-friendly architecture:** clean URLs, internal linking, metadata, semantic HTML, schema markup when relevant, and crawlable navigation.
- **E-commerce performance:** user-focused product pages, mobile shopping UX, and conversion-oriented layout decisions.
- **AI-assisted engineering:** faster prototypes and iterations followed by code inspection, validation, and maintainability checks.
